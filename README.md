# Cat Joke — The One-Line Cat Joke That Lands

Entry for the make.fun competition `u-aldy998-the-one-line-cat-joke-that-lands-a7b18262`.

`main.py` writes one joke about cats — a single line under 200 characters —
to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The joke:

> My cat stared at a blank wall for an hour, then turned to me like a detective who just figured out I'm the murderer.

Run it with:

```sh
python3 main.py
```
